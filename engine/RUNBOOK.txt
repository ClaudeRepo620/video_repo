## 2. Script (Turkish, Rota 360: 55-80 words ≈ 20-30 s · Kokpit 360: 70-95 words ≈ 25-35 s — PLAYBOOK 4a; never pad, never speed the voice up)
- Line 0 = the hook: a bold claim or question, with the promise of a reveal ("…biri Türkiye'de", "sonuncusunu kimse bilmiyor").
- 8-12 lines; one line = one cut (1.5-2.5 s). Max 3 facts. Talk like a person, not like captions. Numbers are written as they are said ("üç bin sekiz yüz").
- Escalate; keep the best for last; the last line asks a question that invites comments ("Sen hangisini…? Yorumlara yaz.").
- **Every fact checked with web search** (2 reliable sources for each number). Put them in `script.json` "sources". If a claim can't be confirmed, cut it.
- `caps`: 1-3 words per chunk, exactly ONE `*yellow` word per chunk, `{spoken}` anchor before a digit chunk (e.g. `{üç} *3.800 yıl`). `say` overrides pronunciation (e.g. "Maçu Piçu").
- script.json keys: title, lang "tr", voice — MALE ONLY (the user's rule since 2026-11-22): "Charon" deep · "Fenrir" · "Orus" · "Puck" bright; never Kore or any female voice, style = ONE audio tag such as "[excited]", "[curious]", "[warm]" (a plain-text direction gets read aloud!), music "travel" | "tension" | "bed", lines.

## 3. Voice
`python3 tools/voice_google.py .` makes ONE Gemini TTS request for the whole script (the free tier allows only a few requests per minute and a limited number per day per model), falls back through the other TTS models on 429, and splits the audio back into lines at its pauses. Vary the voice between videos, male voices only (Charon, Puck, Fenrir, Orus); never a female voice. Style = one audio tag like "[excited]", never a sentence (it gets read aloud).
